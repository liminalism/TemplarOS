# ADR-0008: Toolchain, MSRV, licence and namespace

* **Status:** accepted
* **Date:** 2026-08-17
* **Derived from:** `docs/planning/01-initial-shape.md`, `docs/planning/02-subsequent-shape.md`

## Decision
* Rust edition 2024, resolver 3; dev toolchain 1.97.1 (`rust-toolchain.toml`); **`rust-version = "1.97"`**
  with an MSRV CI job. The workspace uses the real floor of its resolved first-party preview
  dependencies instead of claiming compatibility with a compiler that cannot resolve them.
* Own code MPL-2.0 (repository-wide `LICENSE`); forks keep upstream (GPL-3.0). `deny.toml` licence allow-list;
  DEP-5 `debian/copyright` regenerated by `cargo xtask copyright`.
* Namespace **`org.templaros`** for D-Bus names, app IDs and first-party apps (`org.templaros.Files`,
  `org.templaros.Viewer`); polkit `org.templaros.host.*`; env `TEMPLAROS_APP_ID` / `TEMPLAROS_INSTANCE_ID`.

## Amendment (2026-08-21, ADR-0012)
One exception to "own code MPL-2.0": `compositor/templar-comp` is **GPL-3.0-only**. It is written
against Smithay (MIT) but reads `cosmic-comp` (GPL-3.0-only) as an implementation reference for
driver, XWayland and protocol quirks, and carries that licence deliberately rather than arguing
about where reference ends and derivation begins. MPL-2.0 combines into a GPL-3.0 work, so
`templar-comp` links `templar-window` and `templar-comp-integration` unchanged; nothing links back to it,
so no other crate is affected. `deny.toml` allows GPL-3.0 for this reason.

## Amendment (2026-08-22, ADR-0013)
"Own code MPL-2.0" is replaced by **AGPL-3.0-only** for the whole repository, `templar-comp`'s
GPL-3.0-only exception unchanged. Everything else in this ADR (toolchain, MSRV, namespace,
`deny.toml` allow-list, `cargo xtask copyright`) stands.

## Amendment (2026-08-31, dependency floor)
The workspace MSRV moves from Rust 1.93 to 1.97. The `bpg-*` preview dependencies already require
1.97, so the former MSRV gate failed before compilation and no longer described a buildable
TemplarOS source graph. Development remains patch-pinned to 1.97.1 while `rust-version` expresses the
minor-version compatibility floor.
