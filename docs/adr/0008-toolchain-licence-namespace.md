# ADR-0008: Toolchain, MSRV, licence and namespace

* **Status:** accepted
* **Date:** 2026-08-17
* **Derived from:** `docs/planning/01-initial-shape.md`, `docs/planning/02-subsequent-shape.md`

## Decision
* Rust edition 2024, resolver 3; dev toolchain 1.97.1 (`rust-toolchain.toml`); **`rust-version = "1.93"`**
  (Ubuntu 26.04's rustc) with an MSRV CI job.
* Own code MPL-2.0 (repository-wide `LICENSE`); forks keep upstream (GPL-3.0). `deny.toml` licence allow-list;
  DEP-5 `debian/copyright` regenerated by `cargo xtask copyright`.
* Namespace **`org.legeos`** for D-Bus names, app IDs and first-party apps (`org.legeos.Files`,
  `org.legeos.Viewer`); polkit `org.legeos.host.*`; env `LEGEOS_APP_ID` / `LEGEOS_INSTANCE_ID`.
