# ADR-0013: Own code is AGPL-3.0-only

* **Status:** accepted
* **Date:** 2026-08-22
* **Amends:** ADR-0008 (licence), ADR-0012 (the compositor's GPL-3.0-only exception)

## Decision
* Every first-party crate, interface definition, document and asset in this repository is
  **AGPL-3.0-only** (repository-wide `LICENSE`). The workspace `license` field, `deny.toml`'s
  allow-list, the two Wayland protocol `<copyright>` lines and `cargo xtask copyright`'s default all
  say so; DEP-5 `debian/copyright` carries the full text because Ubuntu's `common-licenses` has no
  AGPL-3 file.
* `compositor/lege-comp` stays **GPL-3.0-only** for exactly the reason ADR-0012 gives (cosmic-comp
  read as a reference). GPLv3 §13 and AGPLv3 §13 each expressly permit combining a GPLv3 work with
  an AGPLv3 work, every part keeping its own licence, so `lege-comp` links `lege-window` and
  `lege-comp-integration` unchanged and nothing links back to it.
* Forks keep their upstream licences (ADR-0005).
* `Silvaview-rs` — the author's SequoiaView port, which previously carried no licence file — is
  relicensed AGPL-3.0-only at the same time, so its pure squarify/colour/cushion modules can be
  lifted into `crates/lege-treemap` (Home Field trays) without a licence boundary inside the tree.

## Context
The Home Field work (`@legeos.work.home-field`) lifts code from Silvaview-rs; the author decided that both
projects should be AGPL-3.0 rather than keeping LegeOS on MPL-2.0 and relicensing only the lifted
modules. A single strong copyleft for the whole desktop also removes the asymmetry ADR-0012
introduced, where one crate was under a stronger licence than the crates it links.

## Consequences
* `cargo deny check licenses` allows `AGPL-3.0` for own code; `MPL-2.0` remains allowed for
  dependencies only.
* Contributions are accepted under AGPL-3.0-only; no CLA.
* Anyone offering LegeOS services over a network must offer the corresponding source (§13) — the
  intended effect.
