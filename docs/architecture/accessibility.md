# Accessibility invariants
The recovery overlay, window shelf, "show every window" and "go home" (`Ctrl+Alt+H` on any keyboard,
`Super+D` where there is a logo key) are keyboard-reachable without the shell;
high-contrast palette variants exist for every shell surface; AT-SPI/orca ship in `a11y.seed`; one input
method (`input-method` role). Everything the shell shows is available through `lege` too.
