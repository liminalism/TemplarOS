# Research

Studies of other systems, done to decide something here. Each one records what was actually read
versus inferred, so a later reader can tell a verified claim from a plausible one.

These are **not** decisions. A finding worth acting on becomes an AKR record or an ADR; this
directory is where the evidence for it stays legible afterwards.
